# 자산·라이선스 고지

## 프로토타입 소스

이 폴더의 새 HTML·CSS·JavaScript 소스는 프로젝트 라이선스인 **Apache-2.0**으로 제공됩니다. 각 소스 파일 상단에 `SPDX-License-Identifier: Apache-2.0`을 표기했습니다. 저장소의 Apache-2.0 `LICENSE`가 우선합니다.

## 직접 만든 자산

다음 자산은 이 프로토타입을 위해 직접 만들었으며, 상용 제품·기관 로고·상용 아이콘 세트를 복제하지 않았습니다.

- 인라인 SVG UI 아이콘: 홈, 장소, 화면, 이미지, 재생, 미리보기, 상태, 등록 등. Lucide 또는 다른 아이콘 패키지를 포함하지 않았습니다.
- 예시 포스터 8장: 가을 공연, 안내 데스크, 공연 일정, 전시, 휴관 안내, 국악기, 교육 프로그램, 새해 인사. 모두 프로토타입용으로 작성한 단순 SVG 그래픽입니다.
- 테스트 화면 그래픽, 로고 대신 사용한 ‘소리결’ 표식, 시나리오·감사 기록용 모의 콘텐츠.

이 이미지들은 실제 기관의 공식 포스터나 로고가 아니며, 실제 공연·전시 정보로 사용하면 안 됩니다.

## 글꼴

폰트 파일을 포함하지 않았습니다. 설치된 운영체제의 한글 글꼴을 다음 순서로 사용합니다.

```css
"Apple SD Gothic Neo", "Malgun Gothic", "Noto Sans KR", "Noto Sans CJK KR", sans-serif
```

Pretendard는 포함하지 않았고 CSS 글꼴 목록에도 넣지 않았습니다. Noto Sans KR/CJK KR이 설치된 환경에서는 해당 글꼴을 사용할 수 있으며, 폰트 파일은 이 저장소에 들어 있지 않습니다. 상업적 환경에서 글꼴을 별도로 번들할 경우 해당 글꼴의 라이선스를 다시 확인해야 합니다.

## KRDS 및 벤치마크

- KRDS의 코드·컴포넌트·아이콘을 복사하지 않았습니다. 정보 구조, 오류 처리, 접근성 원칙, 상태 표현 같은 패턴만 추상화했습니다.
- 해외·국내 상용 제품의 화면, 아이콘, 로고, 고유 문구, 독창적 레이아웃을 복제하지 않았습니다.
- 모든 장소 이름과 운영 데이터는 설명용 가상 예시입니다. 공식 기관 로고·엠블럼을 재현하지 않았습니다.

## 선택적 테스트 도구

`tests/smoke.mjs`는 선택적으로 [Playwright](https://playwright.dev/)를 사용합니다. Playwright는 Apache-2.0 라이선스의 개발 도구이며 이 저장소에 번들하지 않습니다. 테스트를 실행하려면 사용자가 별도로 설치해야 하며, 설치 버전의 라이선스를 따릅니다.

```sh
npm install
npx playwright install chromium
```
