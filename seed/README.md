# 샘플 콘텐츠

첫 실행 시 `poster-autumn.png`, `poster-welcome.png`, `poster-class.png`, `sample-video.mp4`가 업로드 폴더로 복사되고 샘플 재생목록 ‘로비 기본 순환’이 만들어집니다.

- 포스터 3종: 이 저장소를 위해 제작한 가상 예시 이미지입니다. 실제 공연 정보가 아닙니다.
- `sample-video.mp4`: **Big Buck Bunny** (© 2008 Blender Foundation, www.bigbuckbunny.org), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)으로 배포되는 360p 10초 샘플 클립입니다. 원본은 테스트용으로 제공되는 1MB 클립이며, 재생기 동작 확인에만 사용합니다.
- SVG 원본은 `seed/source/`에 있습니다. 포스터 PNG는 Edge 헤드리스로 1920×1080 또는 1080×1920 크기로 렌더링했습니다.

샘플을 끄려면 `SEED_SAMPLES=false`로 실행하세요. 이미 만들어진 데이터는 자동으로 지워지지 않습니다.
