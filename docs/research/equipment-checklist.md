## 8. 현장 진단 절차

1. 모니터·PC·프로그램·USB의 라벨과 화면을 사진으로 남긴다.
2. 아래 진단 스크립트를 각 재생 PC에서 실행한다. 읽기 전용이며, 설치·삭제·설정 변경을 하지 않는다.
3. 같은 이미지 3장(가로 1920×1080 JPEG, 세로 1080×1920 JPEG, 파일명 영문)을 준비해 기존 프로그램에서 재생해 본다.
4. USB를 바꿔 보되, 포맷은 하지 않는다. 가능하면 동일 파일을 다른 USB(FAT32/exFAT)에도 복사해 비교한다.
5. 모니터 1대를 PC에 직접 연결했을 때와 현재 연결 방식(분배기·컨버터·USB 그래픽)을 비교한다.
6. 네트워크가 있다면 서버 PC와 플레이어 PC 사이의 지연을 측정한다(같은 스위치, 유선 우선).
7. 결과를 `docs/research/`에 보관하고, 원본 사진은 개인정보가 없는 것만 공유한다.

## 9. 진단 스크립트

- 경로: `tools/collect-windows-info.ps1` (작성 예정)
- 실행 예:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\collect-windows-info.ps1 -OutDir .\artifacts\site-a
```

- 수집 항목: OS·빌드·아키텍처, PC 모델, CPU·RAM·디스크, GPU·드라이버, 모니터 EDID/해상도/연결, 설치된 프로그램(이름·버전·게시자), 시작 프로그램, 실행 중인 프로세스, USB 저장장치, 브라우저 버전, 네트워크 어댑터·IP·게이트웨이, 전원 설정, 최근 부팅·오류 이벤트.
- 출력: JSON 1개, 사람이 읽는 요약 TXT 1개, 선택적으로 ZIP 1개. 비밀번호·문서 내용·개인 파일은 수집하지 않는다.
- PowerShell 5.1 이상을 기준으로 하고, 일부 WMI 값은 관리자 권한이 없으면 비어 있을 수 있다. 스크립트는 실패한 항목을 `unknown`으로 표시하고 계속 진행한다.

## 10. 이 정보로 결정할 것

- 기존 프로그램 수리로 끝낼 수 있는가?
- Windows 10/11 + Docker 서버가 가능해 Xibo를 도입할 수 있는가?
- 기존 Windows PC를 그대로 쓰려면 경량 자체 개발이 필요한가?
- 한 PC에 여러 모니터를 붙이는가, 모니터마다 PC가 있는가?
- 유선 LAN과 NTP를 보장할 수 있는가?

## 11. 주의

- 이 문서는 개인정보·계약 정보를 수집하지 않는다. PC 사용자 이름, 문서 파일, 메일, 계정은 수집 대상이 아니다.
- 진단 결과와 사진은 원내 자료로 취급하고, owner 허락 없이 외부에 공유하지 않는다.
- 기존 프로그램을 삭제하거나 USB를 포맷하지 않는다. 수리는 별도 승인 후 진행한다.
