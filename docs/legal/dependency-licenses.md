# 외부 의존성·배포 라이선스 전수 감사

기준일: 2026-11-26. 대상은 루트 `package-lock.json`과 `prototype/package-lock.json`의 전체 설치 경로입니다. lockfile에는 120개 package 경로, 119개 고유 `name@version`이 있습니다. `playwright-core@1.65.1`은 두 lockfile에 중복으로 존재하며 표에서 양쪽 설치 위치를 모두 연결합니다.

## 검증 결과

- Windows Node.js 24 환경에서 루트 `npm ci`와 `prototype`의 `npm ci`를 실행했습니다. 각각 92개와 2개 패키지가 설치되었고, lockfile 무결성 검사와 npm audit가 통과했습니다(취약점 0건).
- Windows에 설치되지 않는 26개 `@esbuild/*@0.28.2` 플랫폼 tarball과 `fsevents@2.3.3`을 정확한 잠금 버전으로 별도 내려받아 SHA-512를 lockfile `integrity`와 비교했습니다. 27개 모두 일치했습니다.
- 각 고유 패키지의 원본 라이선스 전문을 설치 패키지의 `LICENSE`/`NOTICE`에서 확인하고 SHA-256과 경로를 표에 기록했습니다. 일반 라이선스 파일이 없는 `cookie-signature@1.0.7`은 패키지 `Readme.md`의 전체 MIT 섹션을, `@esbuild/*` 아카이브는 각 tarball의 MIT 표기와 동일 버전 `esbuild@0.28.2/LICENSE.md`를 대조했습니다. `fsevents` 전문은 잠금 tarball의 `package/LICENSE`에서 확인했습니다.
- `busboy@1.6.0`과 `streamsearch@1.1.0`은 lockfile에 SPDX 필드가 없지만, 잠금된 각 npm 아카이브의 `package.json`에는 legacy `licenses: MIT` 항목이 있고 원본 `LICENSE`도 포함되어 있음을 확인했습니다.

## 사용·배포 범위

- 루트 lockfile에서 Windows production 설치에 해당하는 항목은 75개입니다. 그중 71개가 MIT, 2개가 ISC, 2개가 BSD-3-Clause입니다. `busboy`와 `streamsearch`는 원문에서 MIT로 분류했습니다.
- 나머지 root lock 항목은 개발·테스트 또는 플랫폼 선택 의존성입니다. `fsevents`와 비 Windows `@esbuild/*` 바이너리는 Windows 설치물에 포함되지 않습니다. `esbuild` 자체는 개발 의존성이며 Windows 설치 payload의 production 설치에서 제외됩니다.
- `prototype`의 Playwright 1.65.1 패키지 두 개는 선택적 smoke-test 도구입니다. Windows 앱 payload에는 포함되지 않습니다. `playwright-core@1.65.1`은 root 및 prototype 경로의 `LICENSE`와 `NOTICE`가 동일한 해시임을 기록했습니다.
- `cookie-signature@1.0.7` lock metadata와 package.json에는 MIT가 선언되어 있지만 별도 LICENSE 파일은 없습니다. 설치된 npm archive의 `Readme.md`에 완전한 MIT 전문을 확인했고, Windows payload에 해당 README가 보존됩니다.
- MIT 전문에서 저작권 행을 자동으로 추출할 수 없는 경우에도 원문 경로와 전문 SHA-256은 기록했습니다. 표의 `Copyright`는 package.json author 또는 고지 문서에 나온 값일 수 있으며, 그 자체가 저작권 귀속의 독립 법률 검증은 아닙니다.
- 현재 Windows installer/ZIP 및 Docker 실제 산출물 대조는 이 문서의 패키지 원문 조사와 별도입니다. 그 산출물에서 package license 파일이 남는지와 top-level `NOTICE`가 포함되는지는 #24에서 확인합니다.

## 고지 조건 요약

- MIT/ISC: 각 원본 저작권 표시와 허가문을 유지합니다.
- BSD-3-Clause: 저작권 고지, 조건, 면책 조항을 유지하며 사전 서면 허가 없는 보증·홍보에 권리자 이름을 쓰지 않습니다.
- Apache-2.0: LICENSE와 해당 패키지 NOTICE를 함께 보존하고, 수정 고지·특허·상표 조건을 따릅니다.
- 본 lockfile 집합에서는 GPL/AGPL 등 추가 소스 공개를 요구하는 라이선스를 확인하지 않았습니다. 위 분류와 원문 경로는 아래 패키지별 표에 연결되어 있습니다.

`node_modules` 원문은 해당 lockfile의 package integrity 검증을 통과한 파일입니다. npm cache나 package metadata만을 원문 증거로 사용하지 않았습니다.
