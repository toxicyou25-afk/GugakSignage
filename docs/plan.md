# 단계별 실행 계획

> 개발 방향: 열린안내판은 공공기관 범용 전자 안내판 통합관리시스템이며 국립부산국악원은 최초 실증 대상이다. 기존 아키텍처와 내부 식별자를 유지하고 물리 모니터 자동 인식·전체화면 배치·다중 PC 관리·복구를 우선한다. 기관명·로고 설정 및 기본 샘플 범용화는 후속 작업으로 관리한다.

작성 2026-11-24 / 범용 이미지 송출 + UI·UX 벤치마킹 반영

## 전체 일정(1인 개발 기준)

| 단계 | 기간 | 핵심 결과 | 통과 기준 |
|---|---|---|---|
| 0. 조사·현장 진단 | 1~2주 | 후보 비교, UI·UX 벤치마크, 장비 목록 | 장비 구성과 방향을 결정할 수 있다 |
| 1. UI·UX 설계·프로토타입 | 2~3주 | IA, 화면 설계, 작동형 프로토타입 | 담당 직원 3명 이상이 10분 안에 이미지→송출 완료 |
| 2. 범용 엔진 PoC | 3~4주 | 동적 모니터·배치·모드·미리보기 엔진 | 1·4·8대, 이미지 0·1·3·10장, 4개 모드 통과 |
| 3. MVP 통합 | 4~6주 | 관리 화면 + 서버 + 웹 플레이어 | 사이트 생성→등록→업로드→게시→재생 |
| 4. 현장 시범 | 2~3주 | A센터 무인 운전 | 2주 연속, 재부팅·단절·교체 시험 통과 |
| 5. 확대·인수인계 | 2주 | B센터, 교육, 운영 문서 | 직원이 외부 도움 없이 운영 |
| 합계 | **14~20주** |  |  |

공수 추정은 60~90 person-days다. UI·UX 조사·프로토타입 10~15일, 엔진·서버·플레이어 35~50일, 현장 적용·안정화 10~15일, 문서·교육 5~10일을 포함한다. 장비 확인·보안 검토·일정 조정에 따라 달라진다.

## 0단계: 조사·현장 진단 (1~2주)

### 작업

- 국내외 디지털 사이니지 제품의 실제 화면·매뉴얼·데모·오픈소스 조사
- Xibo·Yodeck·ScreenCloud·OptiSigns·Play Digital Signage·Anthias + ScreenTinker·Concerto + 국내 제품
- KRDS(국내 디지털 정부서비스 UI/UX 가이드라인) 확인
- 후보별 라이선스·유지보수·동기화·범용 배치·한글·초보자 UX 비교
- 현장 장비·기존 프로그램·USB·네트워크·보안 조건 조사
- 저작권·상표권·오픈소스 라이선스 확인

### 결과물

- `docs/research/candidates.md` — 오픈소스 후보 비교
- `docs/research/ui-benchmark-intl.md` — 해외 제품 UI·UX
- `docs/research/ui-benchmark-kr.md` — 국내 제품·공공 UI
- `docs/research/krds.md` — KRDS 요약과 적용 범위
- `docs/research/equipment-checklist.md` — 장비 확인 목록
- `docs/research/licenses.md` — 참고 자산 라이선스

### 통과 기준

- 참고할 패턴과 피해야 할 패턴이 화면 단위로 구분되어 있다.
- 실제 화면·매뉴얼 출처 URL과 확인 날짜가 있다.
- 장비 1~3번(모니터·PC 수·OS)이 확인되어 방향을 정할 수 있다.

## 1단계: UI·UX 설계·프로토타입 (2~3주)

### 작업

- 정보 구조(IA)와 6단계 첫 사용 흐름 확정
- 대시보드, 장소·배치, 화면 등록, 콘텐츠, 재생, 미리보기, 상태·오류 화면 설계
- 초보자 용어·도움말·빈 상태·오류 문구 작성
- KRDS 기반 접근성·한글 가독성 점검
- 작동형 프로토타입(HTML/CSS/JS, mock data) 구현
- 담당 직원 3~5명 사용성 테스트, 막힌 지점 수정

### 결과물

- `docs/design/ui-ux.md` — 원칙·IA·화면 목록
- `prototype/` — 작동형 프로토타입
- `docs/research/usability-test.md` — 사용성 테스트 결과
- 화면 캡처·시나리오 문서

### 통과 기준

- 처음 보는 직원이 이미지 3장을 올려 4대 화면에 순환 송출하는 과제를 10분 안에 완료
- 치명적 오해 0건, “다음에 무엇을 해야 하는지 모르겠다” 20% 이하
- 키보드만으로 업로드·순서 변경·미리보기·게시 가능
- 상용 제품의 화면·아이콘·로고를 복제하지 않았다는 검토 기록

## 2단계: 범용 엔진 PoC (3~4주)

### 작업

- 순수 재생 엔진: 타임라인, 이미지 선택, 배치 매핑, 회전·자르기, 동기화
- 사이트·그룹·모니터·배치·재생목록·이미지 데이터 모델
- 개별·순환·동시·통합 모드
- 이미지 수 ≠ 모니터 수 처리, 패턴 미리보기
- 가상 모니터 미리보기(같은 엔진 사용)
- 이미지 업로드·규격 검사·썸네일
- 브라우저 플레이어, 자동 등록·수동 등록, 하트비트
- 서버 시각·최소 왕복 동기화, 오프라인 캐시
- 1·4·8대, 이미지 0·1·3·10장 자동 테스트

### 결과물

- `poc/engine/` — 순수 엔진 + 테스트
- `poc/server/` — API·mock 데이터
- `poc/player-web/` — 브라우저 플레이어
- `poc/preview/` — 가상 모니터 미리보기
- `poc/README.md` — 실행·검증 방법

### 통과 기준

- 모니터 수·이미지 수를 코드 수정 없이 바꿀 수 있다.
- 4개 모드가 같은 엔진으로 동작한다.
- 미리보기와 플레이어의 RenderPlan이 일치한다.
- 유선 LAN에서 전환 오차 200ms 이내, 1시간 소크 통과.
- 서버 10분 단절·재부팅 후 자동 복구.

## 3단계: MVP 통합 (4~6주)

### 작업

- 프로토타입 UI를 실제 서버·엔진과 연결
- 사이트·모니터·배치·콘텐츠·재생·게시 CRUD
- 관리자 인증·권한·감사 로그
- 이미지 검증·변환·썸네일·안전 영역
- 자동 발견·수동 등록·상태·오류 안내
- 자동 시작·watchdog·절전 해제·백업
- 브라우저 플레이어와 선택형 네이티브 다중 창 어댑터

### 통과 기준

- 사이트 생성부터 첫 송출까지 10분 이내
- 모니터 추가·제거 시 재시작 없이 배치 갱신
- 이미지 100장·모니터 8대에서 목록·미리보기 응답 2초 이내
- 관리자·일반 사용자 권한 분리
- 백업·복구 리허설 성공

## 4단계: A센터 현장 시범 (2~3주)

- 실제 모니터·PC·네트워크에 설치
- 2주 무인 운전, 매일 상태 확인
- 재부팅·정전·네트워크 단절·이미지 교체·모니터 추가/제거 시험
- 담당 직원이 직접 이미지 교체·순서 변경·복구
- 오류·불편 기록 후 수정

### 통과 기준

- 2주 연속 치명 장애 0건(계획된 재부팅 제외)
- 화면 간 전환 오차 200ms 이내(유선 LAN)
- 직원이 도움 없이 이미지 교체 완료
- 장애 발생 시 5분 안에 원인·복구 방법 확인

## 5단계: B센터 확대·인수인계 (2주)

- B센터 설치, 센터별 독립 콘텐츠 확인
- 운영 문서: 설치, 이미지 규격, 교체, 백업, 복구, 장애 대응
- 교육 1회 + 실습 1회
- 유지보수 담당·연락 체계 지정

### 최종 기준

- 담당 직원이 외부 도움 없이 설치·운영·복구 가능
- 2개 센터가 독립적으로 콘텐츠 운영
- 새 장소를 설정만으로 추가할 수 있는 구조 확인

## 역할

| 역할 | 담당 |
|---|---|
| owner | 방향·예산·일정 결정, 현장 협조, 보안 검토 승인 |
| 사무실 총괄(메인) | 설계·기술 판단·검증·보고, 워커 결과 검토 |
| 조사 워커 | 해외/국내 UI·UX, KRDS, 오픈소스 후보 조사 |
| 프로토타입 워커 | 작동형 UI 프로토타입 |
| 엔진 워커 | 순수 재생 엔진·서버·플레이어 |
| 현장 담당자 | 장비 정보, 콘텐츠, 사용성 테스트, 현장 시범 |

## 결정 지점

1. 0단계 후: 기존 프로그램 수리 / 경량 자체 개발 / Xibo·ScreenTinker 파일럿
2. 1단계 후: 프로토타입 UI 확정, 추가 기능 범위
3. 2단계 후: 웹 플레이어만 / 네이티브 다중 창 포함
4. 4단계 후: B센터 확대 / 보완

## 하지 않을 것

- 첫 버전에 동영상·소셜·분석·멀티테넌시·과금을 넣지 않는다.
- 모니터 수·배치를 코드에 고정하지 않는다.
- 상용 제품 화면·아이콘·로고를 복제하지 않는다.
- 확인 없이 기존 프로그램·USB·파일을 삭제하지 않는다.
- 검증 없이 “완성”이라고 보고하지 않는다.
